## Projects

Six projects, on a horizontal timeline on desktop, collapsing to a
vertical stack on a phone. Each card carries the project name, a short
description, and a connecting rule to the next. The dates the projects
were built are not displayed — the projects live on their own timeline,
and dates on the right of a list is a CV tell.

### 1. E-Commerce Platform

A learning project built with HTML, CSS, and JavaScript. It implements
a list of products, a working shopping cart, and a responsive layout
that adapts to different screen sizes. I built it to understand how a
storefront handles the basics: rendering a catalogue, holding cart state
in the browser, and reflowing the grid from desktop to phone.

### 2. AI Chat Assistant

A chatbot built with Python and Streamlit, using the Groq API for
language model inference. The interface accepts user messages and
displays model responses in a conversational flow. I wired up the
request flow end to end: capturing the user's input, posting it to the
model through the Groq API, and rendering the response back in the chat
window. It was my first time calling a language model and getting a
usable answer back.

### 3. AI Text Utility Tool

A small Python utility for cleaning text, counting words, and
reformatting prose. I built this while learning Python through the
GIAIC programme, as a small hands-on exercise. The tool takes a block
of text in and returns it cleaned, with a word count alongside. It
taught me the basics of string handling in Python: how to break a
string into pieces and rebuild it in a new shape.

### 4. Figma Clone Website

A frontend reproduction of the Figma website, built with TypeScript,
HTML, and CSS. I matched the source design closely, paying attention
to layout, typography, and color. The work was an exercise in reading
a real product page and rebuilding it section by section — measuring
type, matching spacing, and copying the colour palette. I tried to keep
the spacing and the type scale honest to the source.

### 5. Registration Form

An interactive registration form with JavaScript-side validation,
built with JavaScript, HTML, and CSS. The form has a responsive layout
and validates user input on the client before submission. I wrote the
validation in JavaScript on the client side, so the form refuses to
submit until the inputs are correct. The layout reflows to a single
column on narrow screens, and the validation messages appear as the
user fills in each field.

### 6. Unit Converter

A Streamlit app, written in Python, that converts values across
multiple measurement categories. The interface lets a user pick a
category, enter a value, and see the converted result. I set up the
interface with a category picker, a value field, and the result
written back to the page. Picking a category swaps the units in the
dropdown; entering a number runs the conversion and updates the result
on screen.
